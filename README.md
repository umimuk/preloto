# LOTO7 予想＆分析ツール

## 概要

ロト7の過去抽選データを自動取得・分析し、次回の予想番号を生成するWebツールです。
出現頻度・連番傾向などの統計的指標を組み合わせたアルゴリズムで予想番号を算出し、選出理由も合わせて表示します。

🔗 **ツールURL**: https://preloto.itoo.workers.dev/

## 機能

- **予想番号生成**: 過去データの分析に基づき、次回の予想番号（7つ）を自動生成
- **選出理由の表示**: 各番号がなぜ選ばれたかをテキストで説明
- **熱い番号 / 冷えた番号**: 直近10回の出現傾向を視覚的に表示
- **予想の保存**: 気に入った予想をローカルに保存し、後から振り返り可能
- **履歴・分析タブ**: 番号別出現頻度グラフや統計情報の可視化

## 使い方

1. **データ読み込み**: ページを開くと、Googleスプレッドシートから最新の過去抽選データが自動読み込みされます
2. **予想確認**: 「今週の予想」タブで予想番号と選出理由を確認します
3. **分析確認**: 「履歴・分析」タブで番号別の出現頻度や傾向を確認します
4. **予想保存**: 「この予想を保存する」ボタンでローカルに保存できます
